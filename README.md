# Usage for ManglerFetch.sh


Mini Fetch :
```bash
  manglerfetch.sh --minimal
```
Full Fetch :
```bash
  manglerfetch.sh --full
```
Different Colors : 
```bash
  manglerfetch.sh --theme cyan
```
No Color :
```bash
  manglerfetch.sh --no-color
```
